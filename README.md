## Pesa Boi Web React + Vite e Node / Express

Olá Dev! Aqui se encontra toda a base e arquivo do Frontend feito em React da nossa aplicação. Nela estão presentes as lógicas, o desiner e as funcionalidades de busca e obitensão de resultados na API .
Na pasta servidores está o nosso Backend com as funcionalidades de conexão com o banco de dados e também as funcionalidades de busca, criação, exclusão e listagem de dados.
Foi realizada a hospedagem da aplicação no Vercel e no Render.
- Deploy: https://pesa-boi-web.vercel.app/

# Tecnologias Utilizadas

- React
- JavaScript
- Node / Express
